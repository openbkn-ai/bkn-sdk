Usage: kweaver-admin audit list [options]

List login audit events

Options:
  --page <n>     Page number (default: "1")
  --size <n>     Page size (default: "20")
  --user <name>  Filter by user name
  --start <iso>  Filter start time (ISO 8601)
  --end <iso>    Filter end time (ISO 8601)
  -h, --help     display help for command
