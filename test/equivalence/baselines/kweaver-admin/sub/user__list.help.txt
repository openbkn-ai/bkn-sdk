Usage: kweaver-admin user list [options]

List users via UserManagement console search-users endpoint

Options:
  --org <orgId>     Filter by department id
  --keyword <text>  Substring match on display name
  --limit <n>       Page size (default 100, max 1000)
  --offset <n>      Page offset (default 0)
  -h, --help        display help for command
