Usage: kweaver-admin auth whoami [options] [url]

Show current user identity. Username resolution: id_token -> access_token ->
persisted token.username -> GET /api/eacp/v1/user/get -> GET
/api/user-management/v1/users/<sub>/account?role=. Successful backend lookups
are persisted back to token.json.

Arguments:
  url          Platform URL (defaults to current)

Options:
  --no-lookup  Skip backend HTTP fallback (eacp/user/get +
               user-management/users/<sub>/account)
  -h, --help   display help for command
