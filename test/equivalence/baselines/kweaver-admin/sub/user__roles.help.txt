Usage: kweaver-admin user roles [options] <user>

List roles currently granted to a user. Accepts a user UUID or account name;
names are resolved via `/api/user-management/v1/console/search-users/account`.
GET /api/authorization/v1/users/<userId>/roles. Use the returned ROLE ID with
`user assign-role` / `user revoke-role`.

Arguments:
  user        User UUID or account/login name (e.g. 'admin' or 'cli-test-...').

Options:
  -h, --help  display help for command
