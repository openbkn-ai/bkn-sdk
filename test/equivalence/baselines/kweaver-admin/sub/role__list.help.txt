Usage: kweaver-admin role list [options]

List roles defined on the platform. The ROLE ID column is the UUID needed by
`role members`, `role add-member`, `user assign-role`, etc. Source filter:
system = built-in, business = product-defined, user = custom.

Options:
  --source <source...>  Filter by role source (system|business|user; repeatable)
  --keyword <text>      Substring search on role name
  --offset <n>          Pagination offset (default 0)
  --limit <n>           Page size (default 100, max 1000)
  -h, --help            display help for command
