Usage: kweaver-admin user reset-password [options]

Admin password reset (defaults to '123456'). Old password is NOT required. Use
--password / -p to set a custom one, or --prompt-password to type it
interactively.

Options:
  -u, --user <idOrAccount>  User UUID or account (loginName). UUIDs are detected
                            by format; anything else is treated as an account
                            and resolved via search.
  --id <userId>             Explicit user UUID. Use this when the id does not
                            match the standard UUID format.
  -p, --password <new>      New password. When omitted, resets to the platform
                            default '123456' (or prompts interactively if
                            --prompt-password is given).
  --prompt-password         Prompt for the new password interactively (input is
                            hidden) instead of passing it on the command line.
  -y, --yes                 Skip the confirmation prompt
  -h, --help                display help for command
