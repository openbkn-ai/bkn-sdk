Call an API with curl-style flags and auto-injected auth headers

USAGE
  kweaver call <url> [-X METHOD] [-H "Name: value"] [-d BODY|-F key=val] [flags]

FLAGS
  <url>                   API path, e.g.
                          /api/ontology-manager/v1/knowledge-networks
  -X, --request           HTTP method (default: GET)
  -H, --header            Extra header (repeatable)
  -d, --data, --data-raw  JSON request body (sets Content-Type: application/json
                          if unset)
  -F, --form              Multipart form field: key=value or key=@/path/to/file.
                          Repeatable. Mutually exclusive with -d
  -bd, --biz-domain       Override x-business-domain (default: bd_public)
  -v, --verbose           Print request info to stderr
  --pretty                Pretty-print JSON output (default)

INHERITED FLAGS
  --base-url, --token, --user, --help

EXAMPLES
  $ kweaver call /api/ontology-manager/v1/knowledge-networks
  $ kweaver call -X POST /api/agents -d '{"name":"demo"}'
  $ kweaver call -F file=@./spec.yaml /api/toolboxes/{id}/tools/upload
