Per-platform business-domain config

USAGE
  kweaver config <subcommand> [flags]

AVAILABLE COMMANDS
  set-bd   Set default business domain for current platform
  list-bd  List business domains as JSON (requires login)
  show     Show current config (platform, business domain)

INHERITED FLAGS
  --base-url, --token, --user, --help

EXAMPLES
  $ kweaver config set-bd 54308785-4438-43df-9490-a7fd11df5765
  $ kweaver config list-bd
  $ kweaver config show

LEARN MORE
  Use `kweaver config <subcommand> --help` for flag details
