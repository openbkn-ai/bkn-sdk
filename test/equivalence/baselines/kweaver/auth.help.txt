Login, list, inspect, and switch saved platform auth profiles

USAGE
  kweaver auth <platform-url> [flags]                 (shorthand for `login`)
  kweaver auth <subcommand> [args] [flags]

AVAILABLE COMMANDS
  login            Login to a platform (browser OAuth2 by default)
  whoami           Show current user identity (from id_token)
  status           Show current auth status
  list             List all platforms and users (tree view)
  use              Switch active platform
  users            List user profiles for a platform
  switch           Switch active user for a platform
  logout           Logout — clear local token
  delete           Delete saved credentials
  export           Export credentials (run printed command on headless host)
  change-password  Change password (interactive or with -u/-o/-n)

FLAGS
  Login
    --alias <name>         Save platform with a short alias
    --no-browser           Print auth URL, prompt for callback URL / code on
                           stdin
    --no-auth              Save platform without OAuth (servers with no auth)
    --http-signin          Force HTTP /oauth2/signin (no browser)
    -u, --username <name>  Username for HTTP signin (prompts for missing pass)
    -p, --password <pwd>   Password for HTTP signin (prompts if -u given but -p
                           omitted)
    --new-password <pwd>   Initial-password reset after 401001017, then retry
                           login
    --client-id ID         Use existing OAuth2 client ID (skip dynamic
                           registration)
    --client-secret S      Client secret (omit for public/PKCE clients)
    --refresh-token T      Headless: exchange refresh token for access token
    --port <n>             Local callback port (default: 9010)

  TLS
    --insecure, -k  Skip TLS certificate verification (dev / self-signed only)

  Scope
    --global  Override profile requirement for `switch`/`use` (CI / single-user
              setup)

INHERITED FLAGS
  --base-url, --token, --user, --help

ENVIRONMENT
  KWEAVER_PROFILE      Scope state.json (active platform/user) to a named
                       profile
  KWEAVERC_CONFIG_DIR  Override config root (~/.kweaver) — hard isolation per
                       shell

EXAMPLES
  $ kweaver auth https://platform.example.com
  $ kweaver auth login https://platform.example.com --client-id <id> --refresh-token <t>
  $ kweaver auth switch --user alice
  $ kweaver auth whoami --json

LEARN MORE
  For agents / multi-terminal scripts: prefer `--user <id>` over `auth switch`
  Use `kweaver auth <subcommand> --help` for action-level details
