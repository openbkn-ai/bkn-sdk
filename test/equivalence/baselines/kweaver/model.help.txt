Model factory — LLM / small-model CRUD (mf-model-manager) + runtime invocation (mf-model-api)

USAGE
  kweaver model llm   <subcommand> [flags]
  kweaver model small <subcommand> [flags]

LLM
  list        List LLM models
  get         Get an LLM model by id
  add         Register an LLM model (--body-file or sparse flags)
  edit        Update an LLM model (merge mode by default)
  delete      Delete one or more LLM models
  test        Run model registration self-test (mf-model-manager)
  chat        OpenAI-compatible chat completion (mf-model-api)
  --template  Print bundled LLM registration JSON stub (offline)

SMALL MODEL
  list        List small models (embedding / reranker)
  get         Get a small model by id
  add         Register a small model (--model-config-file | --adapter)
  edit        Update a small model (sparse-merge or --body-file)
  delete      Delete one or more small models
  test        Run small-model registration self-test
  embeddings  Runtime: POST mf-model-api /small-model/embeddings
  rerank      Runtime: POST mf-model-api /small-model/reranker
  --template  Print bundled small-model config JSON stub (offline)

FLAGS
  --mf-base-url <url>      Override mf-model-manager origin (env:
                           KWEAVER_MF_MODEL_MANAGER_URL)
  --mf-api-base-url <url>  Override mf-model-api origin (env:
                           KWEAVER_MF_MODEL_API_URL)
  -bd, --biz-domain <s>    Business domain (default from config)
  --json                   Print raw API JSON output

INHERITED FLAGS
  --base-url, --token, --user, --help

EXAMPLES
  $ kweaver model llm list --type llm --limit 20
  $ kweaver model llm chat <model_id> -m "hello" --stream
  $ kweaver model small embeddings <model_id> -i "text"

LEARN MORE
  Upstream secrets: prefer --api-key-file over --api-key (shell history)
  Use `kweaver help all` for full per-subcommand signatures
