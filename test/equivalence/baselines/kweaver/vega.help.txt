Vega observability — catalogs, resources, datasets, queries, connector types

USAGE
  kweaver vega <subcommand> [<action>] [flags]

SERVICE
  health   Check Vega service health
  stats    Show catalog statistics
  inspect  Health + catalog summary + running tasks

RESOURCES
  catalog         list / get / health / test-connection / discover / resources /
                  create / update / delete
  resource        list / get / query / create / update / delete / list-all
  dataset         create-docs / update-docs / delete-docs / delete-docs-query /
                  build / build-status
  query           execute — structured query (tables, joins, filters)
  sql             Direct SQL / DSL; use {{<resource_id>}} in SQL (quoted)
  connector-type  list / get / register / update / delete / enable

FLAGS
  -bd, --biz-domain <s>  Business domain (default: bd_public)
  --pretty               Pretty-print JSON (default)

INHERITED FLAGS
  --base-url, --token, --user, --help

EXAMPLES
  $ kweaver vega health
  $ kweaver vega catalog list --status active
  $ kweaver vega sql --resource-type elasticsearch --query 'SELECT * FROM {{r-123}} LIMIT 10'

LEARN MORE
  Use `kweaver help all` for full per-action signatures
  Use `kweaver vega <subcommand> --help` for action-level details (where supported)
