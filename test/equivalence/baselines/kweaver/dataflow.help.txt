Dataflow document workflows — list, run, runs, logs, templates, create*

USAGE
kweaver dataflow <subcommand> [flags]

Commands:
  kweaver dataflow list                     List all dataflows
  kweaver dataflow run <dagId>              Trigger one dataflow run (provide
                                            --file or --url+--name)
  kweaver dataflow runs <dagId>             List run records for one dataflow
  kweaver dataflow logs <dagId>             Show logs for one run in summary or
  <instanceId>                              detail mode
  kweaver dataflow templates                List all available templates
  kweaver dataflow create-dataset           Create a dataset from a template
  kweaver dataflow create-bkn               Create a BKN (knowledge network)
                                            from a template
  kweaver dataflow create [json]            Create a new dataflow (DAG) from a
                                            JSON definition or template

Options:
  --help  Show help                                                    [boolean]
